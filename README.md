# 🔥 ForgeGram

**ForgeGram** — крутой мессенджер, вдохновлённый Telegram.  
С короной. С характером. Без лишней хуйни.

## Сайт

Landing page уже лежит в корне (`index.html`).

После включения **GitHub Pages** (Settings → Pages → Source: Deploy from branch `main` / root) сайт будет доступен по адресу:

**https://floralss.github.io/ForgeGram/**
